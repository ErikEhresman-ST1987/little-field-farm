# Little Field Farm

A small, cheerful farming-and-production game built for touch-friendly mobile browsers.

Plant carrots, wheat, and pumpkins; watch them grow; harvest them into limited storage; sell them at the roadside market or fulfill a customer order; expand the shed; and build a chicken coop that turns wheat into eggs. The farm saves locally, and both crops and chickens continue working while the browser is closed.

## Run locally

Open `index.html` in a browser. No installation or build step is required.
