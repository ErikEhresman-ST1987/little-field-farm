# Little Field Farm

A small, cheerful farming-and-production game built for touch-friendly mobile browsers.

Plant carrots, wheat, and pumpkins; watch them grow; harvest them into limited storage; sell them at the roadside market or fulfill a customer order; expand the shed; raise chickens for eggs; and build a farm bakery that combines wheat and eggs into bread. The farm saves locally, and crops, chickens, and the bakery continue working while the browser is closed.

## Run locally

Open `index.html` in a browser. No installation or build step is required.
