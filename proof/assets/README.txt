Little Field Farm — Graphical Proof 1

Standalone browser visual proof; NOT integrated into the game repository.

Open index.html in a browser. If local file restrictions interfere, serve the folder with: python -m http.server 8000
Then open http://localhost:8000

Drag to pan; pinch/wheel to zoom; tap plots to cycle; use dark-background toggle to reveal edge defects.

Uses the approved 3-panel carrot source through prior selective extraction; artifacts remain experimental, not production-approved. Farm background is a visual candidate, not locked canonical. Rendering uses HTML Canvas for an isolated no-dependency proof; PixiJS game integration remains pending.
